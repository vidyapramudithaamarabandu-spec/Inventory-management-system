# Inventory Management System (IMS)

A custom full-stack web application built to handle stock control, supplier registration, and database management.

## Project Overview
This system was developed in a local WAMP environment. It is engineered strictly for inventory tracking and database management, intentionally omitting sales and transaction processing to provide a clean, streamlined dashboard for stock control.

## Core Features
* **User Authentication: ** Secure login functionality.
* **Supplier Management: ** Interface to add and review supplier details.
* **Stock Control: ** Interfaces to add and review supplier details.
* **Relational Database: ** Structured MySQL backend utilizing foreign keys and normalised tables.

## Technology Used
* **Frontend:** HTML5, CSS
* **Backend:** PHP
* **Database:** MySQL
* **Development Environment** WAMP Server
